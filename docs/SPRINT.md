# Sprint: JobFit-AI

## 1. Epics
- **Document Management (Epic-1)**: Ability to handle various file formats and sources.
- **AI Core (Epic-2)**: High-quality prompt engineering and LLM orchestration.
- **Frontend/UX (Epic-3)**: Professional, easy-to-use interface.

## 2. User Stories
### Epic-1: Document Management
- **STORY-1.1**: As a user, I want to upload my PDF CV and have the system read it accurately.
- **STORY-1.2**: As a user, I want to paste a job URL so the application can extract requirements automatically.

### Epic-2: AI Core
- **STORY-2.1**: As a user, I want an ATS-optimized CV so that I have a better chance of passing automated screenings.
- **STORY-2.2**: As a user, I want a tailored Cover Letter that sounds professional and matches the job tone.
- **STORY-2.3**: As a user, I want the output to be in my specified target language.

### Epic-3: Frontend/UX
- **STORY-3.1**: As a user, I want a split-screen view so I can easily compare the analysis results.
- **STORY-3.2**: As a user, I want to see my "Match Score" so I know how well my current profile fits the job.
